# About
To make videos and images suitable for the Dome, you need to render in the fisheye format or equiretangular format. Both of these are possible with Blender's Cycles renderer. 




# Rendering forward stereo
Set the resolution to a 1:1 aspect ratio under Output Properties. Usually 4096x4096 or 8192x9192. Under output properties enable Stereoscopy. If you want to render a pre-split video use the Individual setting for output. For images and non-split videos enable Stereo 3d and then Side-by-Side (even when rendering a still image you need to Render Animation for the image to save properly).

Select the Camera in the scene. Under Camera Properties change Type to Panoramic and Panorama type to Fisheye Equidistant. Under Camera Properties you can change the Stereo Mode, if you use Off-Axis projection, then 7.4m is the Convergence Distance best suited for the Dome. Also consider how hte pitch of the camera will place objects in the Dome. Rotating the camera 153 degrees upwards will align the 3D world's horizon with teh Dome's horizon.
